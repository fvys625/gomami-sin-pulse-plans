普通国际出口便宜但晚高峰容易拥堵，这是很多低价 VPS 晚上变卡的主要原因。三网优化解决的就是这一段，所以对国内访问敏感的业务会愿意为此付溢价。

## 退款、到期和 DDoS：三条写在小字里的硬规则

这部分是决定「买了之后会不会难受」的关键，也是大多数推荐文不会细讲的地方。

退款只有 **24 小时**窗口。新购 24 小时内可申请全额退款，超过 24 小时一律不退，续费订单一律不退。这跟很多商家 3 天、7 天、30 天无理由退款的节奏完全不同，等于把你的试用期压缩到了一天。想认真测线路，最好在开通当天就把 ping、traceroute、下载速度全跑一遍。 👉 [先看 Mini 配置再决定要不要当天测](https://gomami.io/store/sin-pulse?aff=415)

到期当天立即暂停，没有宽限期。逾期 5 天终止服务，数据可能无法恢复。官方文档没有说明暂停期间数据保留多久，也没有承诺付款后会自动恢复到什么状态，所以别把到期日当成一个可以拖几天的软期限——提前续费，或者先把重要数据备份出来。

DDoS 防护分两层，默认那层是「尽力而为」。所有实例自带基础流量清洗，免费、开箱即用，但官方明确写了无 SLA 承诺，防护容量随攻击规模和网络状况变化。600Gbps 专业清洗是付费加购项，需要联系销售询价，官网没有公开价格。还有一个更硬的机制：当大规模攻击影响到同网段其他客户时，系统会自动对该 IP 执行黑洞，持续 **30–60 分钟**，自动解除，无法人工提前解除。黑洞期间所有进出流量被丢弃，服务完全不可用。官方给的应对建议是自己做基础加固，比如限制 SYN 连接速率、丢弃无效包、限制 ICMP 速率，文档里附了具体的 iptables 命令。
